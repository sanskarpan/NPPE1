## 1. Introduction

**Problem:** Classify chest X-ray images into one of 20 thoracic pathology classes (e.g., Atelectasis, Cardiomegaly, Pneumothorax, No Finding, etc.) using a deep learning model.

**Importance:** Chest radiography is one of the most common diagnostic imaging techniques. Automated classification can assist radiologists by detecting abnormalities faster, especially in high-volume settings where manual interpretation is time-consuming and subject to inter-observer variability.

**Dataset:**

- Training set: 51,043 images (384x384 RGB, grayscale stored as 3-channel)
- Test set: 17,015 images
- 20 classes, single-label (each image belongs to exactly one class)
- Extreme class imbalance: No Finding dominates at 66.77% while Pneumomediastinum has only 5 samples (0.01%)

**Objective:** Maximize the macro-averaged asymmetric competition score:

```
Score_c = (TP_c - FP_c - 5 * FN_c) / N_c
Final Score = (1/20) * sum(Score_c for all classes)
```

False Negatives (missed diagnoses) are penalized 5x more than False Positives (false alarms), reflecting clinical reality where missing a disease is far more dangerous than a false alarm.

## 2. Methodology

### 2.1 Model Architecture

**Backbone:** EfficientNet-B4 with Noisy Student pretraining (`tf_efficientnet_b4_ns` via timm library)

- Chosen because EfficientNet provides excellent accuracy-to-compute ratio, and the Noisy Student variant is pretrained on ImageNet with semi-supervised learning, yielding more robust features
- Total parameters: ~17.6M (all trainable via fine-tuning)

**Custom Classification Head:**

```
Global Average Pooling → BatchNorm → Dropout(0.3) → Linear(1792→512) → SiLU
→ BatchNorm → Dropout(0.15) → Linear(512→20)
```

The head uses two linear layers with SiLU activation, batch normalization for training stability, and dropout for regularization. The final layer was initialized with Xavier initialization.

### 2.2 Preprocessing

- **Image resizing:** Training at 320x320 (speed/memory tradeoff), validation/inference at 384x384 (full resolution)
- **Normalization:** ImageNet statistics (mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]), appropriate since dataset mean intensity (0.502) is close to ImageNet mean (0.485)
- **Data augmentation (training only):**
  - Random horizontal flip (p=0.5)
  - Random rotation (up to 10 degrees)
  - Random affine transform (translate 5%, scale 90-110%)
  - Color jitter (brightness/contrast 0.2)
  - Random erasing (p=0.15, applied after tensor conversion)

### 2.3 Training Strategy

- **Loss function:** CrossEntropyLoss with label smoothing (0.1)
  - No class weights were used in the loss. In an earlier experiment, using inverse-frequency class weights (capped at 10x) combined with Focal Loss caused the model to massively over-predict rare classes, collapsing validation accuracy to just 11% and scoring -9.24 (worse than always predicting No Finding at -4.7). Removing class weights from the loss and instead relying on the Bayes-optimal decision rule at inference was the key fix.
- **Optimizer:** AdamW with differential learning rates
  - Backbone: 3e-5 (lower, since pretrained)
  - Head: 3e-4 (higher, since randomly initialized)
  - Weight decay: 1e-4
- **Scheduler:** OneCycleLR with 10% linear warmup followed by cosine annealing
- **Mixed precision:** Automatic Mixed Precision (AMP) with GradScaler for faster training on GPU
- **Gradient clipping:** Max norm = 1.0
- **No Mixup augmentation:** Disabled because it was harmful with the extreme 6,816x class imbalance
- **No WeightedRandomSampler:** Removed after experiments showed it distorted the learned class distribution

### 2.4 Validation

- **Stratified 5-fold split** (used fold 0 for validation: 40,834 train / 10,209 val)
- Stratification ensured proportional class representation in both splits, critical for ultra-rare classes (e.g., Pneumomediastinum with only 5 total samples)

### 2.5 Inference - Bayes-Optimal Decision Rule

Standard argmax prediction ignores the asymmetric scoring function. I derived a Bayes-optimal decision rule specific to this competition's scoring:

```
c* = argmax_c [(7 * P(c|x) - 1) / N_c]
```

**Derivation:** For this scoring function, predicting class c for a sample contributes +1/N_c if correct (TP), -1/N_c if false alarm (FP for class c), and costs -5/N_c if the true class c is missed (FN). The expected score contribution is maximized by the rule above.

**Key insight:** A rare class with only 30 training samples needs just 14.3% predicted probability to beat No Finding at 50% probability. This is because the 1/N_c normalization in the scoring function gives rare classes disproportionate impact.

**Safety guard:** Ultra-rare classes (N_train < 30) have their N_c clamped to 30 in the decision rule to prevent runaway false positives from the 1/N_c amplification.

### 2.6 Test-Time Augmentation (TTA)

Four augmentations were averaged at inference:

1. Original image
2. Horizontal flip
3. Center crop (110% resize then crop to original size)
4. 10-degree rotation

Softmax probabilities were averaged across all four, then the decision rule was applied.

### 2.7 Automated Strategy Selection

Instead of committing to a single prediction strategy, 13 strategies were evaluated on the validation set:

- Argmax
- Optimal rule with min_train thresholds: 10, 20, 30, 50, 100, 200
- Confidence thresholds: 0.3, 0.4, 0.5, 0.6, 0.7
- Always predict No Finding (safety baseline)

The best-performing strategy on validation was automatically selected for the test submission.

## 3. Experiments and Results

### 3.1 Experiment 1: FocalLoss + Class Weights + WeightedRandomSampler (Failed)


| Setting  | Value                                                          |
| -------- | -------------------------------------------------------------- |
| Loss     | FocalLoss (gamma=2.0) + inverse-frequency weights (capped 10x) |
| Sampling | WeightedRandomSampler                                          |
| Mixup    | alpha=0.2                                                      |
| Epochs   | 30                                                             |


**Result:** Train accuracy 42%, Val accuracy 11%, Val score -9.24. The model over-predicted rare diseases for almost every image. This triple imbalance correction (weighted sampling + weighted loss + focal modulation) completely destroyed probability calibration. The submission also failed due to a `torch.load` crash (PyTorch 2.6 changed `weights_only` default) and a submission format bug (built from sample_submission.csv which had only 10 rows instead of 17,015).

**Key learning:** Class weights in the loss function are counterproductive when combined with an optimal decision rule at inference. The decision rule already accounts for class imbalance.

## 4. Conclusion

### Summary

I developed a chest X-ray classification system using EfficientNet-B4 with Noisy Student pretraining, trained with plain CrossEntropyLoss and natural class distribution sampling. The model was evaluated using a custom asymmetric scoring function that penalizes missed diagnoses (FN) 5x more than false alarms (FP).

### Key Learnings

1. **Class imbalance handling requires careful balance.** Over-correcting with class weights + focal loss + weighted sampling (triple correction) was catastrophically worse than doing nothing. The model scored -9.24 vs -4.7 for the "always predict No Finding" baseline. Removing all three and using a well-calibrated model with a Bayes-optimal decision rule at inference was the correct approach.
2. **Calibration matters more than raw accuracy.** With the asymmetric scoring function, having well-calibrated probability outputs is critical for the optimal decision rule to work. Label smoothing (0.1) and natural sampling helped maintain calibration.
3. **The Bayes-optimal decision rule** `c* = argmax[(7P(c|x)-1)/N_c]` is theoretically the best strategy for this scoring function. In practice, argmax performed comparably because the model's probabilities were not discriminative enough for rare classes to benefit from the 1/N_c boost.
4. **Ultra-rare classes remain the key challenge.** With only 5-37 training samples for the rarest 4 classes, no model architecture or training strategy could learn meaningful features. These classes consistently scored -5.0 (always missed), dragging down the macro average.
5. **Differential learning rates** (backbone 10x lower than head) were essential for effective transfer learning, the pretrained backbone needed gentle fine-tuning while the randomly initialized head needed faster optimization.
